# DSH Drop identity

> **English** · [中文](brand.zh.md)

The mark shows two files landing in a composer tray, with a cursor identifying the drag gesture. It uses the same navy-outline, blue/amber file-card vocabulary as DSH Viewer, without copying its media-grid mark.

Palette: outline navy #253b69, file blue #287bfa, document amber #ffb514, tray blue #d9e8ff, paper #f8fbff. The icon has no text so it remains legible at small sizes. README headings use the reader's native GitHub typography. The social card uses a left-aligned title and a large mark, not a simulated product screenshot.

Source: logo.svg. Raster: logo.png (512 × 512). Social preview: social-preview.png (1280 × 640). Original geometric artwork created for this project, covered by the repository MIT license. Product screenshots contain only synthetic demo files.
